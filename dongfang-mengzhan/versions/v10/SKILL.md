## 1. 全书结构（据书内《分集目錄》核，非推排）

**四集三十四卷**：夢占（卷之首 + 卷1–26，27 卷）· 夢禳（卷27–28）· 夢原（卷29）· 夢徵（卷30–34）。

**夢占 14 部 + 3 图卷**：天象部(卷1–2) · 地理部(卷3) · 人物部(卷4–6) · **形貌部(卷7–9)** · 政事部(卷10–11) · 什物部(卷12–14) · 棟宇部(卷15) · 服飾部(卷16) · 飲食部(卷17) · 蕃彚部(卷18) · 飛走部(卷19–20) · 珍玩部(卷21) · 文翰部(卷22) · 名數部(卷23) · 長柳圖(卷24) · 甘德圖(卷25–26)。

**五脏归属（易错处）**：`臟腑 / 腸胄 / 肺肝 / 膀胱 / 精血 / 魂魄` 等属 **卷之九·形貌部三**（凡十五類），共 12 条判词，**梦林自有脏腑类，不必外求**；脏腑致梦之**理论**在《灵枢·淫邪发梦》（`05`）；《梦林玄解》卷二十九·夢原亦引《素問》《靈樞經》，卷首·玉璅煇遺并沿用「陰氣盛則夢涉大水」语——**理论标灵枢，判词标卷九**，两者不可互相冒充。

**同物异部**：「蛇」分见 地理部（大蛇繞城吉、橋成大蛇橫跨起）· 飛走部（蛇繞于身吉、天誅大蛇）· 形貌部（蛇出兩耳、蛇入臍中）——**必须按梦中出现部位归部**，跨部混判即错。

## 2. 铁律（10 条，违反即失败）

1. **不提问**。一次输出到底，禁任何反问、追问、引导补充。
2. **必须给定判**。禁以「可能/也许/大概/取决于/因人而异」充当结论主体；定论后可另附条件限定句。
3. **原文不可编造**。凡称「原文」，必须能回查本件（给条名 + 行号）。回查不到，只能写「本条未见于本件，依体例推断」或「本轨不作判」，**不得造句子充原文**。
4. **脏腑/二气分管**：理论溯《灵枢·淫邪发梦》；具体判词查卷九·形貌部三「臟腑」类。
5. **图与符不臆造**。卷24–26 图说体、卷28 符式（厭惡夢符式十道、逐日十二道、斬三尸三道）文字不可还原者，**只报篇名与类别，不描述符形、不代拟咒文**。
6. **吉凶并陈并给条件**。同象常有吉凶两判（如天象部「狂風吹折大樹大凶」与「狂風驟雨」并存），必须写清区分条件。
7. **只作文化解读**。不作预测、不作医疗诊断、不替代心理治疗。
8. **末尾加免责行**：「仅供传统文化解读与娱乐参考，不构成医疗、心理或投资建议。」
9. **先给白话总结**：输出第一屏必须是 `【东方综合结论】`（一句话总结＋简单解释），原文与行号置后（见 §12）。
10. **禁用内部代号**：全文不得出现原有「甲乙丙三轨」式代号，三路一律用全称《梦林玄解》·《周易》·《黄帝内经·灵枢经》。

## 3. 三路来源

- **《梦林玄解》查条（本 skill 主来源）**：梦象归部 → 在 `out/02b-entries-zhan-only.csv` 命中条名/占文关键词 → 读占文 → 取判。多象则分判后串判。
  **时令／干支前置查检**：梦中含时令（春/夏/秋/冬、二分二至）或干支日辰（甲乙日…亥子日）时，**先查 `out/14-juan25-category-index.csv`（或 `references/23-juan25-category-index.md`）**，取該條吉凶，再回主表补判。
- **《周易》起象**：大环境为上卦、做梦者为下卦（或动者上、静者下）→ 本卦 → 以变化之象定动爻 → 变卦 → 梅花易数体用（不动为体、有动为用，体宜受生忌被克）→ 系辞（卦辞/彖/象/爻辞/变卦卦辞）→ 归《周礼》六梦（正/噩/思/寤/喜/惧）。
- **《黄帝内经·灵枢经》**：涉情绪梦（怒、恐惧哭泣、善笑、歌乐）与身体感梦（飞扬、坠落、腰脊不属、涉水、大火、相杀、饥取饱予）时启用，按十二盛/十五不足判脏腑虚实。**只讲机理与脏腑归属，不给吉凶判词**。
- **丁轨《夢徵》**（卷30–34，426 条）：征验案例集，只作旁证，**不得当判词使用**；引用格式〔夢徵·卷X·類〕。
- **禳法轨（卷27–28）**：卷二十七为**火珠林系六爻纳甲**（六十四卦爻象之辭、納甲法歌、六神起位賦、卜易總略、論六親、論世應、論持世、論六爻出現伏藏、論日辰、論爻神、論德合刑冲尅墓空生敗死絕共二十叚、吉神、凶煞），用于以梦起卦断吉凶；卷二十八为禳解篇目（寢室卧呪、解辟惡夢、厭惡夢符式、絶三尸、虎枕安神、丹砂治惡夢、鵸䳜禦夢、麝枕、懷夢草 等）。**只报篇目与类别**。

## 4. 查检流程

第 0 步 **梦象抽取**：按六类归料——①天象（日月星斗风云雷雨霞电虹霓雾露霜雪冰雹烟火时令）②地理（地土山水岩石河江湖海城市桥路田园坟墓）③人物（帝王圣贤将相、伦常、僧道鬼神）④形貌（身体头面耳目口齿手足肩腹腰肾心胸脏腑肠肺魂魄）⑤飞走蕃彚（龙蛇鱼鳖禽兽虫豸树木花草果蔬）⑥什物·棟宇·服飾·飲食·政事。另记数量词、动作、情绪。

第 1 步 **主查（默认路径）**：在 `out/02b-entries-zhan-only.csv` 检索梦象关键词，命中即引，标〔卷X·部·類·条名〕+行号。
第 1b 步 **时令/干支查检（卷25–26）**：梦象属天象/地理/人物/服饰/栋宇/节令，且含时令或干支者 → 查 `out/14-juan25-category-index.csv`（類目→鍵→休咎）；引文注「據用戶提供轉錄，未校」。
第 2 步 **扩检**：占条未命中时，查 `out/03-entries-fullbody.csv`（说明文与徵例亦可能含同一象的另判）。
第 3 步 **定位**：仍不确定时，用 `out/01-node-table-595.csv` / `references/09-node-index.tsv` 回到 `data/` 全文读原段。
第 4 步 **外部**：本地无果才走 `06-lookup-protocol.md` 的可用源（维基文库/书格/子夜星/古文道/archive.org），标〔外部检索·来源〕；ctext.org 的《梦林玄解》OCR 残片**禁引**（该站声明会对爬虫返回损坏数据）。
第 5 步 **《周易》起卦**（类象用 03，卦辞用 04，断法结构参 08）。第 6 步 **合参出判**：《梦林玄解》主事象、《周易》主时势；同向加重，相反则两判并列并说明取舍；一轨无判则另一轨独任并注明。

**检索提示**：文件为 UTF-8 BOM，异体字已归一（臓→臟、𦜶→膀、飮→飲、蘁→噩）。排除标题行可加 `grep -v '^[^,]*,.*,—,'`。占条 2644 条集中在 卷1–23 与卷之首。

### 12.4 双语例文（例梦：狂风暴雨的海上，我泡在水中，周围是巨大的海蛇围着我游）

力量很大，路上有阻碍，但你没有真正受伤。
简单解释：
海蛇围着你转，却没有咬你；你泡在水里，却没有沉下去；风浪很大，水也没有干。
这梦说的是：力量已经到了，局面有阻力，但危险里同时带着帮你的东西。

### 12.5 硬规则（违反即失败）

1. **第一句必须是一句话总结**（力量到了／有阻碍／无实害），不得以画面描述开篇。
2. **必须紧跟「简单解释」**，把画面翻译成人话；此段**禁止出现**文言、卦名、脏腑名、行号。
3. 三路结论**平铺**，段首固定用「按……的说法，」；**禁用内部代号**（原「甲乙丙三轨」写法）及「主来源／辅来源」等字样。
4. **必须给确定判词**：禁「可能／也许／大概／取决于／因人而异」充当结论主体；定论后可另附条件限定。
5. **不提问**：一次输出到底，禁反问、追问、「请补充」。
6. `【原文引录】`＝繁体原字＋行号；总结与判词用简体。引号内保留繁体，**两体不得混排**。
7. **原文不可编造**：称「原文」者须能回查（条名＋行号／卦名＋篇）；回查不到写「本条未见于本件，依体例推断」。
8. **梦禳只报篇名**：不作符咒操作、不描述符形、不代拟咒文。
9. 中英双版**同序同义**；英文版来源名作 Menglin Xuanjie (夢林玄解) / Zhouyi (周易) / Huangdi Neijing · Lingshu (黃帝內經·靈樞經)。
