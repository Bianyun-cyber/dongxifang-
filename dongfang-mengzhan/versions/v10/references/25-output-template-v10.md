# 输出模板 v10（单文件，可直接粘贴进 agent）

## 12. 输出模板（v10 通用白话版：总结＋解释；中文＋English 双版）

> **v10 定位**：本 skill 的输出直接进「解梦界面」，用的人不一定是研究者。**第一屏必须是普通人一看就懂的总结＋解释**；原文、行号、卦象放后面作权威背书。
> 三路来源**一律用全称**：**《梦林玄解》·《周易》·《黄帝内经·灵枢经》**。**全文禁用内部代号（原「甲乙丙三轨」写法）**。
> 模板单文件（可直接粘贴）：`references/25-output-template-v10.md`。

### 12.1 固定摆放顺序（不得调换）

1. `【东方综合结论】`＝**一句话总结**（力量到了／有阻碍／无实害 三要素合成一句）
2. `简单解释：`＝把梦境画面**翻译成人话**，2–4 句
3. **按《梦林玄解》的说法，……**
4. **按《周易》的说法，……**
5. **按《黄帝内经·灵枢经》的说法，……**（若梦无脏腑／二气征象，写「此梦未见脏腑征象，本路不作判」，**不得凑句**）
6. `三路合起来都指向同一点：`＋**一句话收束**
7. `【原文引录】`（繁体原字＋行号；无原文则整段省略）
8. `【免责】`

### 12.4 双语例文（例梦：狂风暴雨的海上，我泡在水中，周围是巨大的海蛇围着我游）

```
【东方综合结论】
力量很大，路上有阻碍，但你没有真正受伤。
简单解释：
海蛇围着你转，却没有咬你；你泡在水里，却没有沉下去；风浪很大，水也没有干。
这梦说的是：力量已经到了，局面有阻力，但危险里同时带着帮你的东西。
按《梦林玄解》的说法，蛇绕在身上是吉兆，泡在水里也偏吉，只有「狂风骤雨」一类带阻滞——所以整体偏吉，但带着卡顿。
按《周易》的说法，坎为水、为险，水象重时宜顺势而行，不宜硬顶死守。
按《黄帝内经·灵枢经》的说法，这只是水气偏重、与肾相关的梦象，本身不直接判定好坏。
三路合起来都指向同一点：
这个梦的重点不在「受伤」，而在「散开」和「往前过」。
【原文引录】
　· 《梦林玄解》卷之二十·飛走部·昆蟲「蛇繞于身吉」：仅存条名，占文缺（行 24956）
　· 《梦林玄解》卷之三·地理部·城市「大蛇繞城吉」：「匝蛟龍于棘闈卧英雄于外閫文士變曰化有待經商腰纒萬貫病人不吉之兆」（行 4939）
　· 《梦林玄解》卷之九·形貌部·腹背「少腹浸入水中吉」：「腎旺則夢大水腎虚則夢水涸水侵小肚潔曰淨和樂無意中得財物之夢娶婦得妻財」（行 12427）
　· 《梦林玄解》卷之二·天象部·風雲「狂風驟雨」：「霪雨烈風怒號傾注主朝廷有威命號令常曰人夢之諸事有阻驚險沉迷謀作顚連之狀」（行 2602）
　· 《梦林玄解》卷之二·天象部·風雲「狂風吹折大樹大凶」：「夢此者䘮大臣亡妻子傷勇將損良僕卑幼曰兆此殃家長殞君親行商虧本謀望有阻」（行 2747）
　· 《周易·说卦》：「坎者,水也,正北方之卦也,劳卦也,万物之所归也,故曰劳乎坎。」（见 `references/03-bagua-leixiang.md`）
　· 《黄帝内经·灵枢·淫邪发梦》：「阴气盛,则梦涉大水而恐惧;阳气盛,则梦大火而燔爇;阴阳俱盛,则梦相杀。上盛则梦飞,下盛」（见 `references/05-lingxu-fameng.md`）

【免责】
仅供传统文化解读与娱乐参考，不构成医疗、心理或投资建议。
```

### 12.5 硬规则（违反即失败）

1. **第一句必须是一句话总结**（力量到了／有阻碍／无实害），不得以画面描述开篇。
2. **必须紧跟「简单解释」**，把画面翻译成人话；此段**禁止出现**文言、卦名、脏腑名、行号。
3. 三路结论**平铺**，段首固定用「按……的说法，」；**禁用内部代号**（原「甲乙丙三轨」写法）及「主来源／辅来源」等字样。
4. **必须给确定判词**：禁「可能／也许／大概／取决于／因人而异」充当结论主体；定论后可另附条件限定。
5. **不提问**：一次输出到底，禁反问、追问、「请补充」。
6. `【原文引录】`＝繁体原字＋行号；总结与判词用简体。引号内保留繁体，**两体不得混排**。
7. **原文不可编造**：称「原文」者须能回查（条名＋行号／卦名＋篇）；回查不到写「本条未见于本件，依体例推断」。
8. **梦禳只报篇名**：不作符咒操作、不描述符形、不代拟咒文。
9. 中英双版**同序同义**；英文版来源名作 Menglin Xuanjie (夢林玄解) / Zhouyi (周易) / Huangdi Neijing · Lingshu (黃帝內經·靈樞經)。
10. 末尾固定附免责行。

### 12.6 输出前静默自检（不通过则重写该段）

① 第一行是否为一句话总结；② 是否有「简单解释」段且其中无术语、无行号；③ 三路是否按 梦林玄解→周易→灵枢 固定顺序、均以「按……的说法」开头；④ 全文是否零处内部代号；⑤ 是否无问号、无「请补充」；⑥ 是否无「可能／也许／取决于」作结论主体；⑦ 引文是否均带条名＋行号；⑧ 是否附免责行；⑨ 中英双版是否同序。
