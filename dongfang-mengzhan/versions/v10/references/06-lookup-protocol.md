# 06 · 查检协议（本地全文优先 → 外部检索兜底）

## 零、变更要点（v3）

v2 的协议以「本地摘录 + 外部检索」为骨架，因本地只有摘录，检索实际是主路径。
v3 起 **本地已有全书全文（595 节点）**，故协议倒转：**本地为第一顺位且通常一次命中，外部检索仅作校验与补缺。**

## 一、第一顺位：本地全文（默认路径）

1. 归一梦象关键词（异体字先归通行字：𢆱→真、徃→往、慿→憑、㕥→以、𧰼→象、𢿙→数）。
2. 在 `data/menglin-fulltext-tongxing.txt` 检索关键词。
3. 用 `references/09-node-index.tsv`（节点号/起行/止行/节名）确定所属卷、部、类，读该行段。
4. 命中即引原文，标注〔卷X·部·類〕条名 + 行号。
5. 一篇之内同物异部（如「蛇」分见地理部、飞走部、形貌部）时，**必须按梦中出现部位归部**，不得跨部混判。

## 二、第二顺位：外部检索（本地未命中，或需校验单一来源时）

| 源 | 适用 | 例 |

**仅片段可用源**

| 源 | 限制 |
|---|---|
| 识典古籍 shidianguji.com | 直接抓正文曾失败；只得以检索片段为准，引用须标〔检索片段〕 |

**禁引源**

| 源 | 原因 |
|---|---|
| ctext.org 的《梦林玄解》OCR 残片 | 该站声明会对爬虫故意返回损坏数据，残片字形错乱（如「天渭日月星斗」），引用必致讹 |
| 知乎、百家号、商业解梦站 | 二手且归属不可靠，不得作原文来源 |

## 三、第三顺位：无法核实

- 写「本条未见于本件/未核」，**不得凭条名反推判词**。
- 若确需推断，写「依同部类体例推断」，并单独标明为推断，与原文引录并列而不混同。

## 四、引用格式（强制）

```
〔卷X·部·類〕条名 — 「引文原文」。（行 NNNN；来源：本件 data/menglin-fulltext-tongxing.txt）
〔外部检索·维基文库〕「引文」。
〔夢徵·卷X·類〕案例摘述。（此项只作旁证，不用于取判）
```

## 五、检索纪律

- 同一目标外部检索一轮内不超过两次；命中禁引源立即放弃。
- 符式、图说类（卷二十四、二十五、二十六、二十八）文字不可还原者，**只报篇名与类别**。
- 引文一律不截断于转折处：占文常以前半吉、后半凶，或附条件限定句（如「家临江海者防有水灾至」），截断即等于篡改。
