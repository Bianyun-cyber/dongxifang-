# 八卦类象与取象规则

原文来源:维基文库《易传·说卦》 https://zh.wikisource.org/zh-hans/%E5%91%A8%E6%98%93/%E8%AA%AA%E5%8D%A6 (本会话已抓取核对,全文级)

> 校字说明:维基文库该页将「乾」多作「干」,系该本用字,引用时保留原样并注明。

## 一、八卦性质(说卦)

> 「乾,健也。坤,顺也。震,动也。巽,入也。坎,陷也。离,丽也。艮,止也。兑,说也。」

## 二、动物类象

> 「干为马,坤为牛,震为龙,巽为鸡,坎为豕,离为雉,艮为狗,兑为羊。」

## 三、身体类象

> 「干为首,坤为腹,震为足,巽为股,坎为耳,离为目,艮为手,兑为口。」

## 四、父母子女类象

> 「乾,天也,故称乎父;坤,地也,故称乎母;震一索而得男,故谓之长男;巽一索而得女,故谓之长女;坎再索而得男,故谓之中男;离再索而得女,故谓之中女;艮三索而得男,故谓之少男;兑三索而得女,故谓之少女。」

## 五、万物类象(取象主表)

**乾**

> 「干为天、为圜、为君、为父、为玉、为金、为寒、为冰、为大赤、为良马、为老马、为瘠马、为驳马、为木果。」

**坤**

> 「坤为地、为母、为布、为釜、为吝啬、为均、为子母牛、为大舆、为文、为众、为柄。其于地也为黑。」

**震**

> 「震为雷、为龙、为玄黄、为敷、为大涂、为长子、为决躁、为苍筤竹、为萑苇。其于马也,为善鸣、为馵足,为的颡。其于稼也,为反生。其究为健,为蕃鲜。」

**巽**

> 「巽为木、为风、为长女、为绳直、为工、为白、为长、为高、为进退、为不果、为臭。其于人也,为寡发、为广颡、为多白眼、为近利市三倍。其究为躁卦。」

**坎**

> 「坎为水、为沟渎、为隐伏、为矫輮、为弓轮。其于人也,为加忧、为心病、为耳痛、为血卦、为赤。其于马也,为美脊、为亟心、为下首、为薄蹄、为曳。其于舆也,为多眚、为通、为月、为盗。其于木也,为坚多心。」

**离**

> 「离为火、为日、为电、为中女、为甲胄、为戈兵。其于人也,为大腹、为乾卦、为鳖、为蟹、为蠃、为蚌、为龟。其于木也,为科上槁。」

**艮**

> 「艮为山、为径路、为小石、为门阙、为果蓏、为阍寺、为指、为狗、为鼠、为黔喙之属。其于木也,为坚多节。」

**兑**

> 「兑为泽、为少女、为巫、为口舌、为毁折、为附决。其于地也,为刚卤,为妾、为羊。」

## 六、方位与生成(说卦)

> 「天地定位,山泽通气,雷风相薄,水火不相射。八卦相错,数往者顺,知来者逆。是故易逆数也。」
> 「雷以动之,风以散之,雨以润之,日以烜之,艮以止之,兑以说之,干以君之,坤以藏之。」
> 「帝出乎震,齐乎巽,相见乎离,致役乎坤,说言乎兑,战乎干,劳乎坎,成言乎艮。」
> 「万物出乎震,震,东方也。齐乎巽,巽,东南也……离也者,明也……南方之卦也……坤也者,地也,万物皆致养焉,故曰致役乎坤。兑,正秋也。万物之所说也,故曰说;言乎兑。战乎乾,乾,西北之卦也。言阴阳相薄也。坎者,水也,正北方之卦也,劳卦也,万物之所归也,故曰劳乎坎。艮,东北之卦也,万物之所成,终而所成始也,故曰成言乎艮。」

> 「动万物者,莫疾乎雷。桡万物者,莫疾乎风。燥万物者,莫熯乎火。说万物者,莫说乎泽。润万物者,莫润乎水。终万物、始万物者,莫盛乎艮。」

## 七、取象操作规则

《说卦传》未列之象(如蛇、卫星、舟车细目),依《梅花易数》「万物类象」体例以**属性相从**归卦,并须注明「依类象体例归卦」。常用归纳:

| 梦象 | 归卦 | 依据 |
|---|---|---|
| 风、木、树、竹、藤、长形物、进退不定 | 巽 | 说卦原文「巽为木、为风」 |
| 蛇、长虫、蜿蜒物(龙则归震) | 巽 | 依类象体例引申(长物之性) |
| 水、雨、雪、霜、泉、井、沟渠、险陷、忧愁、盗、月 | 坎 | 说卦原文「坎为水、为沟渎、为隐伏……为加忧、为心病……为月、为盗」 |
| 山、石、门阙、道路、止而不动 | 艮 | 说卦原文「艮为山、为径路、为小石、为门阙」 |
| 日、火、电、甲兵、文书之明丽者 | 离 | 说卦原文「离为火、为日、为电、为甲胄、为戈兵」 |
| 雷、动、决躁、青竹、车声 | 震 | 说卦原文「震为雷……为决躁、为苍筤竹」 |
| 泽、湖沼、口舌、言语、毁折、少女 | 兑 | 说卦原文「兑为泽……为口舌、为毁折」 |
| 天、君、父、金玉、大国、高远、众星、卫星 | 乾 | 说卦原文「干为天、为圜、为君、为父、为玉、为金」 |
| 地、众、母、田土、广大承载 | 坤 | 说卦原文「坤为地、为母……为众、为大舆」 |
| 禽鸟(雉、鸡之属) | 离(雉)或巽(鸡) | 说卦原文 |
| 舟、车、舆 | 坤(大舆)或坎(其于舆也为多眚) | 说卦原文 |
| 屋宅 | 艮(门阙)或坤(承载) | 说卦原文 |

## 八、定上下卦的三条可选法则

1. **环境为上,自身为下**:梦中所处的大环境取上卦,做梦者自身及其所在之处取下卦。
2. **动者为上,静者为下**:梦中移动、变化者为上卦,静止者为下卦。
3. **多者为上,寡者为下**:数量众多者为上卦,单寡者为下卦。

选定其一,并在输出中**说明所用法则**;一象数属时,说明取舍理由。
